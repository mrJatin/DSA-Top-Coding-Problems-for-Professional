📅 Week 1: Foundation Patterns

🎯 Day 1-2: Two Pointers Pattern

Core Concept: Use two pointers moving in opposite directions or at different speeds to solve array/string problems in O(n) time. This technique is particularly useful for sorted arrays and when looking for pairs or triplets.

When to use: Problems involving sorted arrays, finding pairs/triplets, palindrome checking, or array manipulation.

📝 General Template:

public class TwoPointers {
    public int[] twoSum(int[] arr, int target) {
        int left = 0, right = arr.length - 1;
        while (left < right) {
            int sum = arr[left] + arr[right];
            if (sum == target) return new int[]{left, right};
            else if (sum < target) left++;
            else right--;
        }
        return new int[]{-1, -1};
    }
}

1. Two Sum II - Input Array Is Sorted

Problem: Given a 1-indexed array of integers numbers that is already sorted in non-decreasing order, find two numbers such that they add up to a specific target number. Let these two numbers be numbers[index1] and numbers[index2] where 1 ≤ index1 < index2 ≤ numbers.length.

Example:

Input: numbers = [2,7,11,15], target = 9 Output: [1,2] Explanation: The sum of 2 and 7 is 9. Therefore, index1 = 1, index2 = 2.
Solution:
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int left = 0, right = numbers.length - 1;
        
        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) {
                return new int[]{left + 1, right + 1}; // 1-indexed
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
        return new int[]{-1, -1}; // No solution found
    }
}

Explanation: Since the array is sorted, we can use two pointers. Start with left at beginning and right at end. If sum is too small, move left pointer right. If sum is too large, move right pointer left. This guarantees we find the solution in O(n) time.

Time: O(n)
Space: O(1)
2. 3Sum

Problem: Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0. Notice that the solution set must not contain duplicate triplets.

Example:

Input: nums = [-1,0,1,2,-1,-4] Output: [[-1,-1,2],[-1,0,1]]
Solution:
class Solution {
    public List> threeSum(int[] nums) {
        List> result = new ArrayList<>();
        Arrays.sort(nums); // Sort the array first
        
        for (int i = 0; i < nums.length - 2; i++) {
            // Skip duplicates for the first element
            if (i > 0 && nums[i] == nums[i-1]) continue;
            
            int left = i + 1, right = nums.length - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum == 0) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    
                    // Skip duplicates for second and third elements
                    while (left < right && nums[left] == nums[left+1]) left++;
                    while (left < right && nums[right] == nums[right-1]) right--;
                    
                    left++;
                    right--;
                } else if (sum < 0) {
                    left++; // Need a larger sum
                } else {
                    right--; // Need a smaller sum
                }
            }
        }
        return result;
    }
}

Explanation: Sort the array first. For each element, use two pointers to find pairs that sum to the negative of the current element. Skip duplicates to avoid duplicate triplets. The key insight is that after sorting, we can use the two-pointer technique for the remaining two elements.

Time: O(n²)
Space: O(1) excluding output
3. Container With Most Water

Problem: You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]). Find two lines that together with the x-axis form a container that can hold the most water.

Example:

Input: height = [1,8,6,2,5,4,8,3,7] Output: 49 Explanation: The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. The max area is 49.
Solution:
class Solution {
    public int maxArea(int[] height) {
        int left = 0, right = height.length - 1;
        int maxWater = 0;
        
        while (left < right) {
            // Calculate current area
            int width = right - left;
            int currentHeight = Math.min(height[left], height[right]);
            int area = width * currentHeight;
            
            maxWater = Math.max(maxWater, area);
            
            // Move the pointer with smaller height
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return maxWater;
    }
}

Explanation: Start with the widest possible container (leftmost and rightmost lines). The area is limited by the shorter line. Move the pointer at the shorter line inward, as moving the taller line won't increase the area (width decreases and height is still limited by the shorter line).

Time: O(n)
Space: O(1)
4. Remove Duplicates from Sorted Array

Problem: Given an integer array nums sorted in non-decreasing order, remove the duplicates in-place such that each unique element appears only once. The relative order should be kept the same.

Example:

Input: nums = [1,1,2] Output: 2, nums = [1,2,_]
Solution:
class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) return 0;
        
        int writeIndex = 1; // Position to write next unique element
        
        for (int readIndex = 1; readIndex < nums.length; readIndex++) {
            if (nums[readIndex] != nums[readIndex - 1]) {
                nums[writeIndex] = nums[readIndex];
                writeIndex++;
            }
        }
        
        return writeIndex; // Length of unique elements
    }
}

Explanation: Use two pointers - readIndex to scan through array and writeIndex to track position for next unique element. Since array is sorted, duplicates are adjacent. Only write elements that differ from the previous element.

Time: O(n)
Space: O(1)
5. Valid Palindrome

Problem: A phrase is a palindrome if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward.

Example:

Input: s = "A man, a plan, a canal: Panama" Output: true Explanation: "amanaplanacanalpanama" is a palindrome.
Solution:
class Solution {
    public boolean isPalindrome(String s) {
        int left = 0, right = s.length() - 1;
        
        while (left < right) {
            // Skip non-alphanumeric characters from left
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
                left++;
            }
            
            // Skip non-alphanumeric characters from right
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
                right--;
            }
            
            // Compare characters (convert to lowercase)
            if (Character.toLowerCase(s.charAt(left)) != 
                Character.toLowerCase(s.charAt(right))) {
                return false;
            }
            
            left++;
            right--;
        }
        
        return true;
    }
}

Explanation: Use two pointers from both ends. Skip non-alphanumeric characters and compare remaining characters after converting to lowercase. If any pair doesn't match, it's not a palindrome.

Time: O(n)
Space: O(1)
6. Trapping Rain Water

Problem: Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

Example:

Input: height = [0,1,0,2,1,0,1,3,2,1,2,1] Output: 6
Solution:
class Solution {
    public int trap(int[] height) {
        if (height.length == 0) return 0;
        
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int totalWater = 0;
        
        while (left < right) {
            if (height[left] < height[right]) {
                if (height[left] >= leftMax) {
                    leftMax = height[left];
                } else {
                    totalWater += leftMax - height[left];
                }
                left++;
            } else {
                if (height[right] >= rightMax) {
                    rightMax = height[right];
                } else {
                    totalWater += rightMax - height[right];
                }
                right--;
            }
        }
        
        return totalWater;
    }
}

Explanation: Use two pointers and track the maximum height seen so far from both sides. Water at position i is min(leftMax, rightMax) - height[i]. Move the pointer with smaller height as it determines the water level.

Time: O(n)
Space: O(1)
7. Sort Colors (Dutch National Flag)

Problem: Given an array nums with n objects colored red, white, or blue, sort them in-place so that objects of the same color are adjacent, with colors in order red, white, and blue (represented by integers 0, 1, and 2).

Example:

Input: nums = [2,0,2,1,1,0] Output: [0,0,1,1,2,2]
Solution:
class Solution {
    public void sortColors(int[] nums) {
        int left = 0, right = nums.length - 1;
        int current = 0;
        
        while (current <= right) {
            if (nums[current] == 0) {
                // Swap with left pointer and move both
                swap(nums, current, left);
                left++;
                current++;
            } else if (nums[current] == 2) {
                // Swap with right pointer, move right pointer back
                swap(nums, current, right);
                right--;
                // Don't increment current as we need to check swapped element
            } else {
                // nums[current] == 1, just move current
                current++;
            }
        }
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}

Explanation: Use three pointers: left for next position of 0, right for next position of 2, and current for scanning. Swap 0s to left, 2s to right, and leave 1s in the middle. This partitions the array in one pass.

Time: O(n)
Space: O(1)
8. Move Zeroes

Problem: Given an integer array nums, move all 0's to the end of it while maintaining the relative order of the non-zero elements.

Example:

Input: nums = [0,1,0,3,12] Output: [1,3,12,0,0]
Solution:
class Solution {
    public void moveZeroes(int[] nums) {
        int writeIndex = 0;
        
        // First pass: move all non-zero elements to the front
        for (int readIndex = 0; readIndex < nums.length; readIndex++) {
            if (nums[readIndex] != 0) {
                nums[writeIndex] = nums[readIndex];
                writeIndex++;
            }
        }
        
        // Second pass: fill remaining positions with zeros
        for (int i = writeIndex; i < nums.length; i++) {
            nums[i] = 0;
        }
    }
}

Explanation: Use two pointers - one for reading through the array, another for writing non-zero elements. First pass moves all non-zero elements to the front, second pass fills remaining positions with zeros.

Time: O(n)
Space: O(1)
